# IT & Information Security Policy

_Version 3.2 — effective 15 January 2026. Owner: IT Security._

## Passwords and MFA

- Passwords must be at least **14 characters** and are never reused across systems.
- Use the company password manager (1Password) for all work credentials.
- **Multi-factor authentication (MFA) is mandatory** for email, VPN, GitHub and the HRMS portal.
- Passwords are not rotated on a schedule; they are changed immediately if a compromise is suspected.

## Laptops and devices

Company laptops are issued on day one with full-disk encryption enabled. Do not disable the endpoint
security agent. Personal devices may access email and chat only through the managed mobile app.
Lost or stolen devices must be reported to the IT Helpdesk **within 1 hour**.

## Reporting phishing

If you receive a suspicious email, **do not click links or open attachments**. Use the
**"Report Phishing" button** in Outlook, or forward the email as an attachment to
security@acme.example. If you already clicked a link or entered credentials, call the IT Helpdesk
on ext. 4357 immediately — speed matters more than embarrassment.

## Data classification

| Level | Examples | Rules |
|---|---|---|
| Public | Website content, press releases | No restrictions |
| Internal | Handbook, org charts | Share inside Acme only |
| Confidential | Customer data, financials, source code | Need-to-know; never in personal storage |
| Restricted | Salary data, government IDs | Encrypted; access logged and reviewed quarterly |

## Using AI tools

Employees may use the approved AI assistants listed on the IT portal. **Never paste Confidential or
Restricted data into unapproved AI tools.** Generated code must go through normal code review.

## VPN access

The VPN is required to reach internal systems from outside the office. Install the GlobalProtect
client from the Self-Service portal and sign in with your SSO account and MFA.
